niri Link Router

Native bridge

Firefox starts one native host for this profile. No pairing key or request tab is needed.

If disconnected, check that the native host is installed and registered, then reconnect.

Window title label

This label applies to every normal window in this profile. A label of private gives a prefix such as [nfr:123] private .

Your niri screenshare rule can match the label. The router still uses its own window ID.

Recent delivery receipts

Receipts contain no URLs. An opened status means Firefox acknowledged tab creation, not a completed network load.
